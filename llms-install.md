# Install Widely MCP in Cline

Widely is a hosted remote MCP server. Do not clone and run a local process.

1. Open Cline MCP / Remote Servers settings.
2. Add server URL: `https://mcp.widely-mobile.com/mcp`
3. Complete Widely OAuth in the browser (OAuth 2.0 with Dynamic Client Registration). There is no API key.
4. Confirm tools load (numbers, calls, messages, voicemail, quotes, support, and related telecom tools).

Widely: Connect your communications to your AI. Telecom operating layer for AI agents. Category: Communication.

Connecting an AI is free; you pay for Widely membership and usage.
